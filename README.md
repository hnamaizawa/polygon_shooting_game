# POLYGON STRIKE v0.4.0

1980年代の初期3D/ポリゴン・シューティングを思わせる雰囲気を、オリジナル素材だけで再構成したブラウザゲームです。

## v0.4.0 の主な変更

### 4ステージのキャンペーン

1. **EARTH ORBIT** — 地球をバックに戦う
2. **DEEP SPACE** — 宇宙空間をバックに戦う
3. **ENEMY FLAGSHIP** — 敵の巨大戦艦外部をバックに戦う
4. **FLAGSHIP CORE** — 巨大戦艦内部で戦う

各ステージは約5分を目安にしています。通常戦を約4分30秒行った後にボスが出現し、ボスを撃破すると次ステージへ進みます。第4ステージのボス撃破で全ステージクリアです。

### 地上敵

- 甲板・プラットフォーム・艦内床面に地上砲台が出現します。
- プレイヤーのレーザーは空中敵だけでなく、画面上でX/Z位置が合った地上敵にも命中します。
- ステージが進むほど地上敵の出現率と耐久力が上がります。

### 敵の動き・難易度

空中敵は従来より少し速くなり、以下の複数パターンを使います。

- weave: 滑らかな左右蛇行
- zigzag: 速い切り返し
- sweep: 大きな横移動
- hunter: プレイヤーのX位置へ寄る追尾傾向

ステージが進むほど、敵速度・出現間隔・地上敵率・ボスHPが上がります。

### 回転装甲板障害物

- 銀色の薄い装甲板が回転しながら前方から接近します。
- レーザーが命中しても破壊できず、弾だけが消えて火花が出ます。
- 自機が接触するとダメージを受けます。
- ステージが進むほど出現率が少し上がります。
- 特定作品の固有デザインはコピーせず、本作向けのオリジナル障害物として実装しています。

### ボス

- 各ステージ終盤で大型ボスが出現します。
- HUD上部にボスHPを表示します。
- ボスは左右移動と前後移動を組み合わせた軌道で動きます。
- ボス接触時には短い無敵時間を設け、1回の接触で残機が連続消費されないようにしています。

## 操作

- 左右: `← →` または `A D`
- 前進/後退: `↑ ↓` または `W S`
- 射撃: `Space` または `J`
- ミュート: `M`
- リトライ: `R / Enter`

## 起動方法

`index.html` を Chrome / Edge で開き、`MISSION START` を押してください。

## テスト

Windows PowerShell / コマンドプロンプト:

```bat
check_harness.cmd
```

- Node.js がある場合: 構文検査 + `tests/core.test.js`
- Node.js がなく Edge / Chrome がある場合: `tests/browser.test.html`
- どちらもない場合: baseline source/harness checks

v0.4.0 では、4ステージ構成、5分設定、ボス開始時刻、ステージ難易度上昇、地上敵の平面命中判定、複雑な敵移動、回転装甲板の非破壊性・回転移動、ボスHPスケーリングを自動テストします。

## 表現方針

ステージ、機体、地上敵、回転装甲板、ボス、背景、BGM、効果音はすべて本作向けのオリジナル表現です。特定作品の固有モデル・テクスチャ・音源・UI素材はコピーしません。
