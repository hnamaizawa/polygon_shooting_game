# POLYGON STRIKE v0.4.2

1980年代の初期3D/ポリゴン・シューティングを思わせる雰囲気を、オリジナル素材だけで再構成したブラウザゲームです。

## v0.4.2 の主な変更

### 1ステージを約60秒へ

- 1ステージの目安を **90秒 → 60秒** に短縮しました。
- 約50秒でボスフェーズへ入り、ボス撃破で次ステージへ進みます。
- ボス撃破に時間がかかる場合は60秒を超えて継続します。

### 無敵モード

- `I` : 無敵モード ON / OFF
- ON中は敵機、敵弾、ボス、回転装甲板に接触しても残機が減りません。
- HUDに `INV ON/OFF` を表示します。
- ON中の自機には簡易シールドリングを表示します。

### コンティニュー

ゲームオーバー時に `CONTINUE` ボタン、または `C` キーでコンティニューできます。

- ゲームオーバーになったステージの先頭から再開
- スコアを維持
- 背景の累積スクロール位置を維持
- 残機を3へ回復
- コンティニュー回数をHUDに表示

`R` / `Enter` は従来どおり最初からリスタートします。

### 背景を連続スクロール化

背景の移動量をステージ時間とは独立した `worldScroll` で管理し、ステージが変わってもスクロール位置をリセットしません。

ステージ切替時も背景を瞬間的に差し替えず、前の景観と次の景観をスクロールさせたまま短時間で連続遷移させます。

### ステージ1: EARTH SURFACE

1面を「宇宙から地球を見る」表現から、**地球の地表上空を飛んで戦う**表現へ変更しました。

- 青空
- 地平線と山並み
- 緑地
- 道路
- 河川
- 地表オブジェクト

が手前へ連続スクロールします。

## ステージ

1. **EARTH SURFACE** — 地球の地表上空で戦う
2. **DEEP SPACE** — 宇宙空間を進む
3. **ENEMY FLAGSHIP** — 敵巨大戦艦外部を進む
4. **FLAGSHIP CORE** — 巨大戦艦内部を進む

地上砲台、複雑な空中敵、破壊不能の回転装甲板、各ステージのボスは継続して登場します。

## 操作

- 左右: `← →` / `A D`
- 前進/後退: `↑ ↓` / `W S`
- 射撃: `Space` / `J`
- 無敵モード: `I`
- コンティニュー: `C`（ゲームオーバー時）
- BGM ON/OFF: `B`
- テクスチャ ON/OFF: `T`
- 全音声 ON/OFF: `M`
- 最初からリトライ: `R / Enter`

## 起動方法

`index.html` を Chrome / Edge で開き、`MISSION START` を押してください。

## テスト

Windows PowerShell / コマンドプロンプト:

```bat
check_harness.cmd
```

- Node.js がある場合: 構文検査 + `tests/core.test.js`
- Node.js がなく Edge / Chrome がある場合: `tests/browser.test.html`
- どちらもない場合: baseline source/harness checks

v0.4.2 では、60秒ステージ、50秒ボス開始、EARTH SURFACE、無敵時の残機維持、コンティニュー状態復元、敵弾、回転装甲板、4ステージ構成を自動テストします。
