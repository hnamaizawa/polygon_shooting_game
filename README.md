# POLYGON STRIKE v0.3.1

PC-8801mkIISR 時代の初期3D/ポリゴン・シューティングを思わせる雰囲気を、オリジナル素材だけで再構成したブラウザゲームです。

## v0.3.1 の主な変更

- カメラをさらに後方へ引き、俯角を強めた斜め上からの後方視点へ変更
  - `cameraPitchDeg: 30`
  - `cameraBackOffset: 4`
- 自機と敵機を同じ飛行平面へ固定
  - 自機・敵とも `flightPlaneY` を共有
  - 左右移動 + 前後(Z)移動が主体の、2Dシューティングに近いレーン感
- 自機・敵機のテクスチャをより強い金属光沢へ変更
  - 高輝度の反射帯
  - パネルライン
  - ハイライトと擦り傷
  - 動くスペキュラーハイライト
- 巨大宇宙戦艦/空母の甲板にも同じ光沢金属テクスチャを適用
- BGM音量を引き上げ、32ステップのオリジナル・キャッチーメロディーへ変更
- 既存のレーザー・爆発・被弾・GAME OVER効果音と `M` ミュートを維持

## 操作

- 左右: `← →` または `A D`
- 前進/後退: `↑ ↓` または `W S`
- 射撃: `Space` または `J`
- ミュート: `M`
- リトライ: `R / Enter`

`↑ / ↓` は画面上の上下移動ではなく奥行き(Z)移動です。自機と敵は同じ水平飛行面に存在します。

ブラウザの自動再生制限に合わせ、BGM/効果音は `MISSION START` またはキーによる開始操作後に有効になります。

## テスト

Windows コマンドプロンプト / PowerShell で:

```bat
check_harness.cmd
```

- Node.js が PATH にある場合: JavaScript 構文検査と `tests/core.test.js` を実行する Node.js full mode
- Node.js がない場合でも Edge / Chrome が見つかれば: `tests/browser.test.html` を実行する browser full mode
- Node.js も Edge / Chrome も検出できない場合のみ: baseline mode

v0.3.1 では、前進/後退のZ軸操作、共通飛行平面、後方へ引いた高角度カメラ設定も自動テストします。

## 表現方針

1980年代の初期3Dシューティングに見られる、斜め後方視点、奥行き表現、低ポリゴン感、金属的なSFメカ、巨大艦艇のスケール感を研究対象にしています。機体・敵・UI・テクスチャ・BGM・効果音・背景構造などの固有素材はコピーせず、本作向けのオリジナル表現にしています。
