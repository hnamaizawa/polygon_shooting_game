# POLYGON STRIKE v0.5.1

1980年代の初期3D/ポリゴン・シューティングを思わせる雰囲気を、オリジナル素材だけで再構成したブラウザゲームです。

## v0.5.1 の主な変更

### 自機レーザーをチャージ制へ変更

- `Space` / `J`: 通常のパルス弾
- `L` 長押し: レーザーをチャージ
- 約1.35秒チャージすると、約1秒間レーザーを自動照射
- 照射後は再チャージが必要
- チャージ途中で `L` を離すと、蓄積量はゆっくり減衰
- HUD の WEAPONS 欄にチャージ量／照射残時間を表示
- 破壊不能回転装甲板に当たるとレーザーは遮断され、装甲板は破壊されません

敵側のレーザーは従来どおり、BEAM FIGHTER、LASER TURRET、ボスが **予告線 → レーザー照射** の順で使用します。

### Stage 2〜4 の背景表現を強化

Stage 2 / DEEP SPACE:
- 多層の星空と星雲
- 遠方の惑星
- 大きさや形が異なる小惑星・デブリ
- 立体感のある宇宙アウトポスト

Stage 3 / ENEMY FLAGSHIP:
- 巨大戦艦の側壁・甲板・パネル段差
- ハンガー、トレンチ、排気口、砲台区画
- ランウェイライト、縁取り照明、上部構造物

Stage 4 / FLAGSHIP CORE:
- 床・左右壁・天井で構成した内部通路
- フレーム／リブ構造
- 導管、配管、ゲート、ベイ
- 発光するリアクター区画

`worldScroll` はステージ間でも連続し、各背景は従来どおり区画単位で変化します。

### 隠れキャラ

オリジナルの隠れキャラ **GOLDEN SCOUT** を追加しました。

- 各ステージで1回だけ出現機会があります
- 景観の端から短時間だけ現れます
- 通常弾またはチャージレーザーで発見可能
- 発見すると **7,777点** のボーナス
- ゲームクリアには必須ではありません

出現位置・タイミングの詳細は、隠れキャラらしさを残すためREADMEには記載していません。

## 維持される主な仕様

- 4ステージ、各60秒固定
- 約50秒でボス登場
- 連続マップ構成
- INTERCEPTOR / FIGHTER / DART / RAIDER / BOMBER / BEAM FIGHTER
- 地上敵、LASER TURRET、敵レーザー
- `I`: 無敵モード
- `C`: ゲームオーバー時のコンティニュー
- `B`: BGM ON/OFF
- `T`: テクスチャ ON/OFF
- `M`: 全音声 ON/OFF
- 固定1/60秒ステップによるスロー化対策
- 破壊不能回転装甲板

## 起動方法

`index.html` を Chrome / Edge で開き、`MISSION START` を押してください。

## テスト

Windows:

```bat
check_harness.cmd
```

Node.js がある場合は構文検査と `tests/core.test.js`、Node.js がない場合は Edge / Chrome のブラウザフォールバックテストを実行します。
