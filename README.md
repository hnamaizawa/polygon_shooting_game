# POLYGON STRIKE v0.2.0

PC-8801mkIISR 時代の初期3D/ポリゴン・シューティングを思わせる雰囲気を、オリジナル素材だけで再構成したブラウザゲームです。

## v0.2.0 の主な変更

- カメラを、より高い位置の斜め後方から前方を見下ろす「elevated rear chase view」に変更
- カメラ俯角をさらに 24° まで上げ、より強い見下ろし感へ調整
- 遠方の敵ほど上方の地平線側へ集約される、俯瞰感のある投影へ変更
- 自機と敵機をワイヤーフレーム主体から、面を持つ低ポリゴンモデルへ変更
- 自機を細長い胴体・後退翼・双発ノズルを持つオリジナルの80年代SF戦闘機シルエットへ再設計
- 64x64 のオリジナル・プロシージャルテクスチャを生成し、各三角ポリゴンへアフィンテクスチャマッピング
- 金属グラデーション、反射ハイライト、パネルライン、擦り傷を加えたメタリック外装へ変更
- 背景に巨大宇宙戦艦の装甲甲板を追加し、中央発光トレンチ、装甲パネル、砲塔風構造物、船体シームを描画
- ポリゴン面ごとの簡易シェーディングを追加
- HUD の自機表示も塗りつぶしポリゴン表現へ変更
- 既存の移動、レーザー、敵出現、当たり判定、スコア、残機、GAME OVER は維持

## 起動方法

1. フォルダー内の `index.html` を Chrome / Edge で開きます。
2. `MISSION START` を押します。
3. 操作:
   - 移動: 矢印キー または WASD
   - 射撃: Space または J
   - リトライ: R / Enter

Webサーバー、Node.js、外部画像ファイルはゲーム実行には不要です。テクスチャはブラウザ上で生成します。

## テスト

Windows コマンドプロンプト / PowerShell で:

```bat
check_harness.cmd
```

`check_harness.cmd` 自体の実行に Node.js は必須ではありません。

- Node.js がない場合: 必須ファイル、ゲームバージョン、主要コア関数、テクスチャマッピング実装、ハーネスのガードレールを確認する baseline mode を実行します。
- Node.js が PATH にある場合: baseline mode に加えて JavaScript 構文検査と `tests/core.test.js` の単体テストを実行する full mode になります。

## 開発方針

今後も以下を守ります。

1. 自然言語で要件を追加
2. ハーネス / ガードレールを先に維持
3. 必要箇所だけ修正
4. 回帰テスト
5. GitHub PR
6. 人がレビュー
7. 承認後にマージ

## 参考にした画面上の特徴

1980年代の初期3Dシューティングに見られる、高い斜め後方視点、黒い宇宙空間、右側HUD、遠方へ収束するプレイフィールド、低ポリゴン感、金属的なSFメカ、巨大艦艇のスケール感を研究対象にしています。ゲーム名・機体・敵・UI部品・テクスチャ・背景構造等の固有素材はコピーせず、本作向けのオリジナル表現にしています。
