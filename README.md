# POLYGON STRIKE v0.4.1

1980年代の初期3D/ポリゴン・シューティングを思わせる雰囲気を、オリジナル素材だけで再構成したブラウザゲームです。

## v0.4.1 の主な変更

### ステージ時間

- 1ステージの目安を **5分 → 1分30秒（90秒）** に短縮しました。
- 約75秒でボスフェーズへ入り、ボス撃破で次ステージへ進みます。
- ボス撃破に時間がかかる場合は90秒を超えて継続します。

### 弾とゲームテンポ

- 自機の連射間隔を `0.16秒 → 0.22秒` に変更し、画面上の自機弾を少し減らしました。
- 空中敵・地上砲台・ボスがプレイヤー方向へ弾を撃つようになりました。
- 敵弾は弾幕になり過ぎない程度の頻度にし、後半ステージほど少し増えます。
- 敵弾数は上限を設け、描画負荷が無制限に増えないようにしています。

### スロー化対策

従来は1フレームの更新時間を33msで切り捨てていたため、フレームレートが落ちた際にゲーム全体がスローモーションになることがありました。

v0.4.1 では **1/60秒固定ステップ + catch-up update** に変更し、一時的なフレーム落ちでもゲーム内時間・移動速度が遅くなりにくいよう改善しています。長時間停止時には処理の暴走を防ぐ上限があります。

また、パーティクル数と敵弾数にも上限を設けています。

### BGM ON / OFF

- `B` : **BGMだけ** ON / OFF
- `M` : BGM + 効果音を含む全音声のマスターON / OFF

HUD下部に現在のBGM状態を表示します。

### テクスチャ ON / OFF

- `T` : テクスチャマッピング ON / OFF
- ON: 従来の金属光沢テクスチャ
- OFF: 面ごとのフラットな低ポリゴン表示

ゲーム途中でも即時切替できます。ゲームルールや当たり判定は変わりません。

## ステージ

1. **EARTH ORBIT** — 地球をバックに戦う
2. **DEEP SPACE** — 宇宙空間をバックに戦う
3. **ENEMY FLAGSHIP** — 敵巨大戦艦外部をバックに戦う
4. **FLAGSHIP CORE** — 巨大戦艦内部で戦う

地上砲台、複雑な空中敵、破壊不能の回転装甲板、各ステージのボスは継続して登場します。

## 操作

- 左右: `← →` / `A D`
- 前進/後退: `↑ ↓` / `W S`
- 射撃: `Space` / `J`
- BGM ON/OFF: `B`
- テクスチャ ON/OFF: `T`
- 全音声 ON/OFF: `M`
- リトライ: `R / Enter`

## 起動方法

`index.html` を Chrome / Edge で開き、`MISSION START` を押してください。

## テスト

Windows PowerShell / コマンドプロンプト:

```bat
check_harness.cmd
```

- Node.js がある場合: 構文検査 + `tests/core.test.js`
- Node.js がなく Edge / Chrome がある場合: `tests/browser.test.html`
- どちらもない場合: baseline source/harness checks

v0.4.1 では、90秒ステージ、75秒ボス開始、連射抑制、敵弾ロジック、ステージごとの敵弾増加、回転装甲板、4ステージ構成を自動テストします。
