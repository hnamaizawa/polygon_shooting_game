# POLYGON STRIKE v0.3.0

PC-8801mkIISR 時代の初期3D/ポリゴン・シューティングを思わせる雰囲気を、オリジナル素材だけで再構成したブラウザゲームです。

## v0.3.0 の主な変更

- 操作を奥行き移動型へ変更
  - `↑ / W`: 前進（ワールド座標の Z を増加）
  - `↓ / S`: 後退（ワールド座標の Z を減少）
  - `← → / A D`: 左右移動
- `↑ / ↓` では自機の画面上の高さを変更せず、斜め後方視点の奥行き方向へ移動
- 前進・後退は近距離/遠距離の安全範囲でクランプ
- Web Audio API によるオリジナルのレトロBGMを追加
- レーザー、敵撃破、被弾、ゲームオーバーの効果音を追加
- `M` キーでBGM/効果音をミュート切替
- 外部音声ファイルは不要。BGM/効果音はブラウザ上でリアルタイム生成
- 既存の高い斜め後方カメラ、金属的な低ポリゴン機体、巨大宇宙戦艦背景を維持

## 起動方法

1. フォルダー内の `index.html` を Chrome / Edge で開きます。
2. `MISSION START` を押します。
3. 操作:
   - 左右: `← →` または `A D`
   - 前進/後退: `↑ ↓` または `W S`
   - 射撃: `Space` または `J`
   - ミュート: `M`
   - リトライ: `R / Enter`

ブラウザの自動再生制限に合わせ、BGM/効果音は `MISSION START` またはキーによる開始操作後に有効になります。

## テスト

Windows コマンドプロンプト / PowerShell で:

```bat
check_harness.cmd
```

- Node.js が PATH にある場合: JavaScript 構文検査と `tests/core.test.js` を実行する Node.js full mode
- Node.js がない場合でも Edge / Chrome が見つかれば: `tests/browser.test.html` を実行する browser full mode
- Node.js も Edge / Chrome も検出できない場合のみ: baseline mode

v0.3.0 では、前進/後退が Z 軸方向へ移動し Y 座標を変更しないことも自動テストします。

## 表現方針

1980年代の初期3Dシューティングに見られる、高い斜め後方視点、遠方へ収束するプレイフィールド、低ポリゴン感、金属的なSFメカ、巨大艦艇のスケール感を研究対象にしています。機体・敵・UI・テクスチャ・BGM・効果音・背景構造などの固有素材はコピーせず、本作向けのオリジナル表現にしています。
