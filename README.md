# POLYGON STRIKE v0.1.0

PC-8801mkIISR 時代の初期3D/ポリゴン・シューティングを思わせる雰囲気を、オリジナル素材だけで再構成したブラウザゲームの初期プロトタイプです。

## v0.1.0 でできること

- 遠近法付きの3D星空
- ワイヤーフレーム/低ポリゴン風の自機と敵
- 敵機の奥から手前への侵入
- 自機の上下左右移動
- 2連レーザー射撃
- 敵との当たり判定・撃破・スコア
- プレイヤーとの衝突・残機・GAME OVER
- AREA 表示と右側HUD
- 奥行きグリッドによるスピード感

## 起動方法

1. フォルダー内の `index.html` を Chrome / Edge で開きます。
2. `MISSION START` を押します。
3. 操作:
   - 移動: 矢印キー または WASD
   - 射撃: Space または J
   - リトライ: R / Enter

Webサーバーは不要です。

## テスト

Windows コマンドプロンプト / PowerShell で:

```bat
check_harness.cmd
```

`check_harness.cmd` 自体の実行に Node.js は必須ではありません。

- Node.js がない場合: 必須ファイル、ゲームバージョン、主要コア関数、ハーネスのガードレールを確認する baseline mode を実行します。
- Node.js が PATH にある場合: baseline mode に加えて `tests/core.test.js` のJavaScript単体テストを実行する full mode になります。

ゲーム本体の実行にも Node.js は不要です。Chrome / Edge だけでプレイできます。

## 開発方針

今後も、これまでのアプリと同様に以下を守ります。

1. 自然言語で要件を追加
2. ハーネス / ガードレールを先に維持
3. 必要箇所だけ修正
4. 回帰テスト
5. GitHub PR
6. 人がレビュー
7. 承認後にマージ

## 参考にした画面上の特徴

当時の『シルフィード』に見られる、黒い宇宙空間、画面右側の縦長HUD、白/赤を中心とした高コントラスト表示、奥から敵が迫る構図を研究対象にしました。ただしゲーム名・機体・敵・UI部品・グラフィック等はコピーせず、本作向けのオリジナル表現にしています。
